# 🌦️ Weather App

A simple JavaScript application that displays the current weather of any city using the **OpenWeatherMap API**.

---

## Features
- Search for current weather by city name.  
- Displays:
  - Current, minimum, and maximum temperature  
  - Feels-like temperature  
  - Humidity level  
  - Weather description  
  - Icon representing the current condition  
- Clean, minimal, and easy-to-use interface  
- Results shown in **Spanish**

---

**Public API:** [OpenWeatherMap](https://openweathermap.org/api)
